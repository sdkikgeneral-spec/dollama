### Y-1. `docs/fast-mode-plan.md:546` —「−34% はラウンド B 側の実数」は一次証拠で決まらない

旧記述の `−34%` が B 由来だとは一次証拠では決められない。
→ 「どのペアから採られたかは特定できない (A の平均 −33.8% とも B の min −34.0% とも整合)。
A の min ペアは −33.4%」と書き換えるのが安全。放置すると次の是正で秒の側を B に「直される」経路がある。
