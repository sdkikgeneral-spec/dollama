[注意]
======================================================================
  - 本 T2c では src/ を一切変更していない (conv2d.cu 未変更・両セッションとも porcelain 空)。
  - 秒はすべて DOLLAMA_PROFILE=1 の同期入り計時であり、非 profile の wall ではない。

    default は 1 step = 2 forwards)。構成をまたいだ resnet 秒の直接比較はしない。
  - nsys 系の被験 exe は prof_arena_e2e であり、T2c 本走の test_diffusion_batch2 とは別物。
  - t2c_collect_sha256.txt = 回収後に record-writer が採った両側突合の結果。
